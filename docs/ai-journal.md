# Журнал роботи з AI

## Запити та результати

| Крок | Запит до AI | Результат | Перевірка та рішення |
|---|---|---|---|
| 1 | Проаналізувати умову лабораторної роботи та визначити вимоги варіанта 1 | Визначено стек C++17, CMake, GoogleTest/CTest і обов'язкові компоненти агента | Вимоги зіставлено з методичними вказівками |
| 2 | Створити manifest агента, skills і commands для C++-проєкту | Створено `.github/agents`, `.github/skills` і `.github/prompts` | Перевірено наявність усіх обов'язкових файлів |
| 3 | Створити C++ Hello World, CMake і GoogleTest | Створено `src/`, `tests/` і `CMakeLists.txt` | `ci.bat` виконав configure, build і CTest |
| 4 | Додати кросплатформний GitHub Actions workflow | Додано matrix для Ubuntu, Windows і macOS та `ci.sh`/`ci.bat` | YAML перевірено статично; реальний запуск потребує GitHub repository |
| 5 | Виконати `/check` | Перша перевірка виявила відсутній C++ compiler | Після появи Visual Studio повторний `/check` пройшов |

## Помилка та виправлення

Під час першої локальної перевірки CMake не знайшов C++ compiler:

```text
CMAKE_CXX_COMPILER not set, after EnableLanguage
```

Причина — перевірка виконувалась у середовищі без MSVC, `g++` або `clang++`.
Після встановлення/доступності Visual Studio Build Tools повторний запуск
`ci.bat` успішно виконав конфігурацію, компіляцію та CTest. Відмова не була
замаскована.

## Безпека

До AI не передавались паролі, токени, приватні ключі чи інші секрети.
Перед завершенням виконано пошук секретоподібних рядків; збігів не знайдено.
