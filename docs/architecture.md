# Архітектура AI-агента

## Призначення

Агент автоматизує створення мінімального C++17 Hello World-проєкту, його
CMake-конфігурації, тестів GoogleTest і GitHub Actions. Він не вважає роботу
успішною без фактичного складання та проходження тестів.

## Взаємодія компонентів

| Компонент | Вхід | Результат | Перевірка |
|---|---|---|---|
| `build-engineer.agent.md` | вимоги користувача | правила роботи агента | наявність ролі, обмежень і критеріїв |
| `project-scaffold` | мова, назва проєкту | `src/`, `README.md`, `.gitignore` | вихідний файл і команда запуску |
| `build-and-test` | вихідний C++-проєкт | `CMakeLists.txt`, `tests/` | CMake configure/build і CTest |
| `github-actions` | готовий build/test | `.github/workflows/ci.yml`, `ci.sh`, `ci.bat` | YAML, три runner-и, запуск скриптів |
| commands | параметри попередніх етапів | зміни відповідного етапу | очікувані файли та exit code |
| `init` | чистий або частково готовий репозиторій | повний проєкт і звіт перевірки | послідовний запуск усіх commands |

Оркестратор передає наступному кроку стан репозиторію та список створених
файлів. Якщо команда завершується з помилкою або не створює обов'язковий файл,
`init` зупиняється і повідомляє причину; наступні кроки не запускаються.
Повторний запуск є безпечним: команди спочатку перевіряють наявні файли й
оновлюють лише потрібний вміст.

## Безпека

Агент не читає і не створює секрети, не видаляє файли, не виконує `git reset
--hard`, не переписує історію та не змінює захист гілок. Команди складання
запускаються лише після явної перевірки конфігурації.

## Відповідність структурі

Використано стандартні для GitHub Copilot каталоги `.github/agents`,
`.github/skills`, `.github/prompts`; їх функціональні ролі відповідають
`agents/`, `skills/` і `prompts/` у методичних вказівках.
