# Використання та перевірка

## Команди агента

Команди зберігаються в `.github/prompts/` і запускаються з Copilot Chat у
контексті кореня репозиторію:

1. `git-init` — перевіряє Git і `.gitignore`;
2. `create-project` — створює Hello World;
3. `create-build` — додає CMake і GoogleTest;
4. `create-actions` — додає локальні CI-скрипти та workflow;
5. `check` — лише читає структуру й запускає перевірки;
6. `init` — оркеструє попередні кроки саме в такому порядку.

## Локальна перевірка

```sh
./ci.sh
```

Очікується створення `build/`, виконуваного файлу `hello` (або
`hello.exe`) і успішне проходження `BasicAddition`. Каталог `build/` має бути
ігнорований Git:

```sh
git check-ignore -q build
```

Для повторного запуску використовуйте ту саму команду: конфігурація CMake
оновлюється без дублювання файлів.

## GitHub Actions

Workflow запускається для `push` і `pull_request` у `master` або `develop`.
Результати трьох matrix-конфігурацій зберігаються в GitHub Actions як окремі
job-логи. Посилання на успішний запуск і Pull Request слід додати до звіту
після публікації власного репозиторію.
